        CAPABILITIES & DEEP DIVE
        
Everything TCPView does — plus power-user workflows.

        

          Designed for systems engineers, security analysts, and developers who live in the terminal.
        

      


      

        

          
⚡

          
Real-Time Diff Highlighting p

          

            Enumerates all IPv4 & IPv6 TCP and UDP endpoints at configurable intervals (250ms–60s). Newly created sockets flash green, state transitions turn yellow, and closed sockets linger for one tick in red. Press p anytime to freeze live updates for inspection while ETW timestamps continue buffering in the background.
          

        


        

          
📊

          
EStats Bandwidth Charts B

          

            Reads per-connection Extended TCP Statistics (GetPerTcpConnectionEStats) directly from the Windows IP Helper API. Open the live rolling bar chart (B) to monitor 60-sample Tx/Rx throughput deltas for the entire system or press Tab to isolate the currently selected socket.
          

        


        

          
🔍

          
Structured Filter Language /

          

            Full tokenizer, recursive-descent boolean parser, and AST evaluator supporting 17 fields, 10 comparison & regex operators, wildcards (*, ?), byte units (kb, mb, gb), and nested and/or/not logic with live match counts, inline syntax diagnostics, and quick presets on keys 1–8.
          

        


        

          
🛡️

          
Authenticode, Services & Users Enter

          

            Resolves every PID to its executable path, hosting Windows SCM service (e.g., unpacking svchost.exe service names), owning user account, and cryptographic Authenticode signature validity via WinVerifyTrust — complete with a 2-minute Unicode traffic sparkline.
          

        


        

          
🛰️

          
Experimental ETW Kernel Mode --etw

          

            When launched elevated with --etw, tcptui subscribes to the Microsoft-Windows-Kernel-Network ETW provider for real event-driven connect/disconnect timestamps and logs short-lived transient connections that occur between polling intervals. Automatically falls back to polling if unavailable.
          

        


        

          
🚨

          
Alert & Coloring Rules A

          

            Define filter expressions that trigger an alert banner (⚠), event log record, and optional terminal bell whenever a matching new endpoint appears. Switch to the Colors tab to configure ordered Wireshark-style row styling rules (foreground, background, bold, underline).
          

        


        

          
✂️

          
Close Socket & Batch Actions c / K

          

            Immediately tear down established IPv4 TCP connections using SetTcpEntry (c) — the exact Win32 API used by Sysinternals TCPView — or terminate owning processes (K). Mark multiple rows with Space or Shift+↑/↓ to execute batch connection resets or process kills.
          

        


        

          
🌍

          
GeoIP Flags, Whois & VirusTotal w / V

          

            Drop a MaxMind GeoLite2-Country.mmdb file next to the binary to automatically enable the Country column with flag badges. Run built-in recursive RFC 3912 whois lookups (w) or query VirusTotal reputation reports (V, with the virustotal Cargo feature).
          

        


        

          
🖱️

          
Profiles, Mouse & Headless Dump Ctrl+P

          

            Click column headers to sort (Shift+Click appends to multi-key sort chain), drag column edges to resize, scroll horizontally with Shift+Wheel, or right-click any row for the context menu. Export/import named TOML profiles (P) or capture headless screenshots with --dump-frame.

Formal Filter Grammar & Syntax Examples

          
# Grammar (src/filter.rs)
expr    := or
or      := and ( ("or" | "||") and )*
and     := not ( ("and" | "&&") not )*
not     := ("not" | "!") not | primary
primary := "(" expr ")" | field op value | word
op      := "=" "==" "!=" ">" ">=" "<" "<=" ":" "=~" "!~"

# Practical Examples
process=chrome*             # wildcard match (* and ?)
process:chrome              # case-insensitive substring
process=~^(chrome|msedge)   # regular expression (!~ negates)
state=close                 # prefix match (matches CLOSE_WAIT)
pid>1000 and tx>10MB        # numeric & byte units (b/kb/mb/gb)
addr=192.168.* and port=443 # matches either local or remote side
service="WinHttpAutoProxySvc" # quoted strings with spaces

        INTERNALS & ENGINEERING
        
Zero-Async Architecture & Release Timeline

        

          Clean separation between socket enumeration, snapshot diffing, DNS/GeoIP background workers, and deterministic Ratatui rendering.
        

      


      

        

          
01 · COLLECTOR THREAD

          
net.rs · proc.rs · services.rs

          
Polls IPv4/IPv6 TCP & UDP tables via netstat2 & Win32 IP Helper EStats, enriches PIDs via sysinfo, and maps Windows SCM services.

        

        

          
02 · KERNEL & ENRICHMENT

          
etw.rs · dns.rs · geoip.rs

          
Optional Microsoft-Windows-Kernel-Network ETW trace session, non-blocking per-lookup DNS threads, and MaxMind GeoLite2 Country reader.

        

        

          
03 · STATE & QUERY ENGINE

          
model.rs · filter.rs · app.rs

          
Computes snapshot diffs (new/changed/deleted), preserves first-seen ages, evaluates structured filter ASTs, alerts, and coloring rules.

        

        

          
04 · DETERMINISTIC TUI

          
events.rs · ui/table.rs · ui/popups.rs

          
Pure event → state → render loop backed by Ratatui & Crossterm, tested with headless TestBackend and fuzz-tested filter round-trips.
