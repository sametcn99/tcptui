SNAPSHOT DIFF ENGINE // src/model.rs

Deterministic State Diffing

merge_snapshots() diffs consecutive socket tables by 5-tuple identity (Proto, LocalAddr:Port, RemoteAddr:Port), preserving first_seen ages and synthesizing ghost rows for closed connections.

SECURITY TELEMETRY // src/actions.rs

WinVerifyTrust Authenticode & SCM Unpacking

Inspect any socket to verify its executable's cryptographic signature via Windows WinVerifyTrust, resolve the SID token owner (DOMAIN\User), and unpack shared svchost.exe processes into exact service names.

KERNEL TRACE // src/etw.rs

Event Tracing for Windows (--etw)

Polling alone misses sub-second connections. With --etw in an elevated shell, tcptui opens a real-time trace session on Microsoft-Windows-Kernel-Network for true connect timestamps and transient connection logging.

[21:14:08.412] ETW CONNECT pid=44910 curl.exe 192.168.1.111:55104 -> 93.184.216.34:443 [21:14:08.609] ETW DISCONNECT (duration 197ms)
